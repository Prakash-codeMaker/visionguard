VISIONGUARD API

REST API Reference

The deployed assessment API. JSON responses are structured and image uploads use multipart/form-data; the browser also sends deterministic pixel features.

GET/api/healthService + model status
POST/api/v1/analyzeAnalyze one image
GET/api/v1/analysesRetrieve history
GET/api/v1/analyses/{id}Retrieve one analysis
GET/api/v1/analyses/{id}/heatmapRetrieve heatmap URL
POST/api/v1/analyze/batchAnalyze up to 20 images
GET/api/v1/modelModel metadata
GET/api/v1/evaluateReproducible synthetic evaluation metrics
GET/api/v1/self-testOwner-only automated checks
